~/admin/connect

This page saves straight to your website's GitHub repository. It needs a GitHub access key that can only touch this one repository.

  1. Open GitHub → new fine-grained token ↗
  2. Name it website admin, pick an expiry (a year is fine).
  3. Repository access → Only select repositories → marvelelijah.github.io
  4. Permissions → Repository → Contents: Read and write. Optional: Actions: Read-only (shows when an update is live).
  5. Generate, copy the key, paste it below.
repository settings

The key is kept only in this browser. Anyone who can use this browser while it's remembered can edit your site, so don't tick "remember" on a shared computer.
